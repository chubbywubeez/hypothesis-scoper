# Quick GitHub Connection Steps

After you create the repository on GitHub, you'll see a page with setup instructions.

Copy the repository URL from GitHub. It will look like:
- HTTPS: `https://github.com/TheAhaMoment/hypothesis-scoper.git`
- SSH: `git@github.com:TheAhaMoment/hypothesis-scoper.git`

Then run these commands:

```bash
git remote add origin https://github.com/TheAhaMoment/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

Replace `YOUR_REPO_NAME` with your actual repository name.
